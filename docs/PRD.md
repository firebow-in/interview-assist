# PRD — Luminal Insight Dashboard

## 🎯 Strategic Objective

Develop a professional, user-centric analytics platform that transforms interview recordings (video/audio) into actionable behavioral insights using AI-driven scoring and high-impact visual dashboards.

---

## 👤 Target Segments

- **Corporate Talent Teams**: For rapid, objective screening and initial assessment.
- **Academic Counselors**: For student preparation and mock interview analysis.
- **Candidate Self-Review**: For self-driven improvement in communication and reasoning.

---

## 🏗️ Intelligence Features (MVP)

### 1. Luminal Design System
- **Navy Dashboard**: A premium dark-theme interface for data clarity.
- **Branding**: Professional logo (⚜️) and clear hierarchy.

### 2. Analytical Intelligence
- **AI Composite Match Score**: A single, high-level percentage for match evaluation.
- **Pattern Matching (ASR)**: High-fidelity transcript generation from Whisper.

### 3. Visual Dashboards
- **Performance Charting**: Dynamic bar chart to visualize four core metrics.
- **Feedback Taxonomy**: 
    - **Strengths (💠)**: Positive core candidate propositions.
    - **Areas for Improvement (⚠️)**: Risk identification and growth opportunities.

### 4. Interactive Components
- **Playable Preview**: Native in-browser video playback (H.264).
- **Transcript Accordion**: Searchable, clean-text transcripts.

---

## 🧪 User Journey

1. **Upload**: User uploads recording to the sidebar.
2. **Analyze**: System stages the file, transcribes, and scores.
3. **Review**: User explores the dashboard cards and visual charts.
4. **Compare**: User watches the playable preview to confirm the AI feedback.

---

## ⚙️ Qualitative Requirements

- **Efficiency**: Standard 2-minute recording processed in < 60s.
- **Compatibility**: 100% of standard MP4/MKV files must be playable after analysis.
- **Aesthetics**: Professional-grade design to bridge the gap between prototype and product.

---

## 🚫 Out of Scope (Next Release)

- **Talent Pool**: Collaborative candidate ranking.
- **Radar Profile**: Multi-candidate benchmarking.

## 📈 Success Indicators
